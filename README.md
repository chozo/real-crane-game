# 現実版クレーンゲーム 駐車場編

駐車場にびっしり停まった本物サイズの車を、巨大ガントリークレーンで1台ずつ釣り上げて回収ゾーンへ運ぶ 3D ミニWebゲーム（Three.js 製・縦型 9:16・単一ファイル HTML）。全5ラウンド。高い車を狙え、でも隣にぶつけたら弁償。

- 公開URL：https://game.chozo.net/real-crane-game/
- GitHub：https://github.com/chozo/real-crane-game

## 遊び方

1. タイトル画面の「スタート」で開始（このタップで音が有効になる）
2. 十字パッドでクレーンを動かす。爪の真下の車がそのまま狙いになり、上のパネルに価値と左右の隙間が出る
3. 「下ろす」で爪を下ろす。車に届くと自動で掴み、引き抜いて運搬の高さまで上げる（下降中は「上げる」で中止できる）
4. 揺れに気をつけて回収ゾーン（GET）まで運び、「置く」。急に動かすと揺れが育ち、隣の車にぶつけたり、落として大破・爆発したりする
5. 結果カードに写真（GET の瞬間／爆発の瞬間）とスコアが出る。5ラウンドの合計で終了

スコア＝価値×状態−隣の車の弁償。価値＝車種ごとの基本価格×（1−傷）。PC ではキーボード（矢印キーまたは WASD で移動、スペース／Enter で操作ボタン）でも遊べる。

## ビルドとテスト

```sh
npm install                 # 初回だけ：three@0.187.0・playwright-core・wrangler
npm run build               # = node build.js：dist/real-crane-game/ を作り直す（毎回 dist/ を空にする）
npm test                    # ロジックテスト（38件）
npm run test:screens        # 実ボタン操作で5ラウンド通しプレイ（64項目・約4分）
npm run test:explode        # 振り落として爆発・失敗写真を確認（16項目）
npm run test:v26            # 自動掴みと丸い印の追従
npm run models              # 車種ごとの造形の確認画像
npm run sway                # 揺れの収束時間の計測（ロジックのみ）
npm run ogp                 # public/ogp.png と apple-touch-icon.png を作り直す（先に build。作り直したら再 build で dist にも反映）
```

- `build.js` は `src/game.html` に three.js r187（`node_modules` から、ESM を classic script に変換）と `src/logic.js` を埋め込み、単一ファイルの `index.html` を作る。公開用に `dist/real-crane-game/` へ `index.html` と `public/` の中身を出す。ルートにも同じ `index.html` を書く（ローカル確認用。リポジトリには含めない）
- ブラウザのテストは playwright-core でインストール済みの Google Chrome（`channel: 'chrome'`、ヘッドレス・SwiftShader）を使い、`dist/real-crane-game/index.html` を開く。先に `npm run build` が必要
- 手元で遊ぶ：`cd dist && python3 -m http.server 8080` → http://127.0.0.1:8080/real-crane-game/

## ユーザーが決めた仕様（変えるときは先に相談すること）

- 舞台は駐車場だけ（家・ATM は v2 で廃止）。白線2列×6区画に10台、車種は6種
- 対象の事前選択はしない。クレーンを自由に動かし、爪の真下の車がそのまま狙いになる
- 価値＝車種ごとの基本価格×（1−傷）。スコア＝価値×状態−弁償。隣に車がいるほど価値が上がる「囲まれ度」と★の表示は廃止（2026-11-24。v2〜v2.6 では基本価格×囲まれ度 最大×1.95 だった）
- 揺れは「強く育つが、待てば収まる」が現行調整（v2.1 で強め→v2.5 で減衰を3倍に戻した。数値と計測結果は下記 v2.5 の項）
- 値札は全車常時表示だが、狙いの車だけ消える（v2.4。操作の邪魔になるため）
- タイトル画面に車種ごとの金額の目安は出さない（2026-11-24）
- 車体の色：スポーツカーは赤か黄色、オープンカーは青か白（2026-11-24。`src/logic.js` の `CAR_TYPES[].colors`。テストで固定）
- ガントリーの構造物は奥側だけ。画面の手前に脚・梁・レールを出さない、半透過もしない（v2.4）
- 落とした車は激しさに応じて大破・爆発し、黒焦げの残骸が残る（v2.2）
- 結果カードには「写真」を出す。写真は大きく（カード幅88%）。失敗写真は爆発のピーク（激突0.3秒後）に撮る（v2.3・v2.5）
- 車は前後と車種が識別できる造形にする。ただし寸法・重心・当たり判定の数値は変えない（v2.3）
- 爪を下ろしたら自動で掴んで運搬の高さまで上げる。手で押すのは「下ろす」「下降の中止（届くまで）」「置く」だけ（v2.6）
- クレーン位置を示す地面の丸い印は、爪の真下に毎フレーム追従する（v2.6。`markerPos` が爪先座標から算出）

## 技術的な注意

- **JS文字列の中に `<a href=` を書かないこと**。Muse アプリの添付プレビューで単一ファイルを開いたとき黒画面になる（実測で特定済み）。リンクは `createElement('a')` で組む。`build.js` は混入を検出すると失敗する
- テスト用フック `window.__crane` はテスト群が依存している。消す・変えるときはテストも直す
- 写真は `preserveDrawingBuffer` を使わず、撮影の瞬間だけ写真用カメラで描き直して同期取得する方式（チラつき防止）

## ゲーム内容と版ごとの詳細（v2.6 までの記録）

白線の区画に車がびっしり停まった駐車場から、好きな1台の真上へクレーンを動かし、巨大ガントリークレーンで真上から釣り上げて回収ゾーンへ運ぶ。全5ラウンド（1ラウンド＝1台）。仕様は `SPEC.md`（旧仕様は `SPEC_v1.md`）。

- 流れ：ラウンド開始直後から十字パッドで自由に移動 → 爪の真下の車がライブで狙いになる（HUD に価値・左右の隙間）→「下ろす」→ 車に届いたら自動で掴んで自動で引き抜き・巻き上げ（v2.6）→ ゾーンで「置く」
- v2.1 の揺れ：減衰を大きく下げ（吊った車 c=0.05〜0.07/s、半減に約20〜28秒）、吊った時の加減速も強化（1.15 m/s²・加加速度 2.5）。押しっぱなしで運んで離すと大きく揺れて止まらない。収まるのを待つか、吊り荷がぶら下がっている側へ小刻みに寄せて殺す
- 値札は全車に常時表示（狙いの車だけ消える＝v2.4）。爪の大きさは真下の車に合わせて自動で変わる
- 価値＝基本価格 ×（1 ＋ 左右の車 0.3×台数 ＋ 背中合わせの車 0.2 ＋ 奥の列 0.15）×（1 − 傷）
- スコア＝価値 × 状態 − 隣の車の弁償（落下・取れずは弁償だけ引かれる）
- 隣の車との接触（2段階）
  - 爪の下降：開いた指先が隣の車にかかると「こすった」（弁償3%）、深くかかると「ぶつけた」＝隣の車に乗り上げて掴めない（弁償8%、1回分消費）
  - 吊った車：引き抜き中に動かす・揺れる・傾くと隣の車に当たる。ゆっくりなら「こすった」（状態−5%×車種係数）、速いと「ぶつけた」（状態−15%×係数、隣の車も10%弁償・傷が残り価値が下がる）
- v2.2 の大破・爆発：吊った車が落ちて地面に激突すると、当たった速さと落ちた高さ（`wreckPower`、0.2〜1）に応じて `wreckPlan` の量で、タイヤ・ドア・ボンネット・屋根・破片が飛び散り、火の玉・炎・煙・衝撃波・火花・閃光（画面＋照り返しの光）・大きな画面シェイク・爆発音（WebAudio 合成）。車体はつぶれて黒焦げになり、焦げ跡と一緒にゲーム終了まで駐車場に残る（しばらくくすぶって炎と煙を出す）
- v2.2 の写真：GET の瞬間（ゾーンに置いて爪が上がったところ）と、爆発の瞬間（v2.5 で 0.3 秒後に変更）に、写真用カメラ（`photoShot`）で 3D 画面を描き直して 2D キャンバスへ同期的に写し取り、ポラロイド風の額（テープ・日付の焼き込み・キャプション）で結果カードに出す。`preserveDrawingBuffer` は使わない（撮る瞬間だけ描き直し、同じタスク内で普段のカメラで描き直すのでチラつかない）
- 車種：軽自動車／コンパクト／セダン／ワゴン／オープンカー／スポーツカー（色・形・価格・傷の付きやすさが違う）
- v2.3 の写真：結果カードの写真を幅 88% に拡大（文字の板は詰める）、印画紙は 640px。撮影カメラは `photoFit` で対象の箱（GET＝車の足跡×高さ、失敗＝つぶれた車体＋炎と煙の分）の8つの角が画角の約9割に収まる距離まで寄る。GET は車の前（奥向きの車は後ろ）から斜め 42° の 3/4 ビュー
- v2.3 の車のモデリング（見た目だけ。寸法・重心・当たり判定は不変）：横から見た形を車種ごとに押し出し（軽＝背が高い箱／コンパクト＝ハッチバック／セダン＝3ボックス／ワゴン＝屋根が後端まで・垂直テールゲート＋ルーフレール／オープン＝座席・ハンドル・フロントガラス枠／スポーツ＝低く長いノーズ・ファストバック・ウイング）。前＝ヘッドライト（ボンネットの角まで回り込み、上からも白く見える）・グリル・橙のウインカー・ナンバー、後＝赤いテールライト（デッキの角まで回り込む）・ナンバー・マフラー・反射板。サイドミラー、ピラーで区切った窓（Canvas）、ドアの切れ目とハンドル、ホイールアーチ、車種ごとの意匠のホイール。爆発では実際の位置・大きさのドア（窓・ハンドル付き）、斜面に合わせたボンネット、前後バンパー、ミラー、ガラス付きの屋根が飛ぶ
- v2.4：狙い（爪の真下の車）の値札だけ非表示（`setAim` で前の狙いを再表示・新しい狙いを非表示。価値・隙間は上のパネル）。ガントリーは奥側だけ：レールは駐車場の奥で左右方向に左端〜右端の外まで（両端に車止め）、走行台車・A 字の脚・頭部（看板）はその上。駐車場の上・手前には脚・梁・レールを置かず、半透過の部材も廃止。上部のトロリーは小型化し、ケーブルと爪で位置が読める。確認用に `__crane.craneLayout()`
- v2.5 の揺れ：減衰を少し戻した（吊った車 c=0.15〜0.21/s、半減に約7〜9秒。v2.1 の3倍）。運搬中に育つ揺れの最大は v2.1 の約8〜9割のまま、押しっぱなしで運んで止めた後、待つだけで 2° 以下に収まるまで約17〜31秒（v2.1 は約51〜98秒）。計測は `node tests/sway_measure.js`
- v2.5 の失敗写真：激突の 0.3 秒後（`WRECK_PHOTO_AT`）＝火の玉が最大級で部品が宙を飛び散っている最中に撮る。写す箱は「つぶれた車体＋火の玉の芯＋車の周り約1m以内を飛ぶ部品」。失敗写真だけ爪とケーブルは写さない（0.3秒時点では爪が火の玉の真上に来て隠すため）。確認用に `__crane.info().boomFx`（火の玉の大きさ・宙の部品数・飛散距離）
- v2.6 の自動掴み：状態機械は logic の `AUTO`/`autoNext`/`manualAction`。下降が車に届いた時点で自動で爪を閉じ（`closing`→`closed`）、自動で引き抜き・巻き上げ。こすり・ぶつけ・地面着地で掴めなかった場合も自動で巻き上げて戻る（試行回数は従来どおり消費）。下降中は「上げる」で中止でき、車に届くまでは手動で巻き上げ直せる
- v2.6 の丸い印：地面の丸い印は `markerPos(crane, cable, swing)`＝爪先の真下座標から毎フレーム算出する。以前は狙いの車が変わったときにしか印が更新されず、車に当たるまで初期位置に残る不具合があった
